# Generics, Set and Map in Java

In this module, I studied Generics and some of the most important collection structures available in Java, focusing on Set and Map.

The goal was to understand how to create reusable code with Generics and how Java collections manage data efficiently.

## Topics Covered
- Generics
- Generic methods
- Generic types
- Wildcards (`?`)
- Bounded wildcards
- Set collection
- HashSet
- TreeSet
- LinkedHashSet
- Map collection
- HashMap
- TreeMap
- LinkedHashMap
- `equals()` and `hashCode()`
- `Comparable`
- Set operations (union, intersection and difference)

## Key Concepts
- Generics allow creating reusable and type-safe code.
- `Set` represents a collection of unique elements without duplicates.
- `HashSet` provides the fastest access but does not maintain order.
- `TreeSet` keeps elements ordered according to `compareTo` or a `Comparator`.
- `Map` stores data using key-value pairs.
- `HashMap` offers fast access through hash tables.
- `equals()` and `hashCode()` are essential for collections that use hashing.
- `Comparable` allows defining a natural ordering for custom objects.

## Exercises
The exercises were focused on applying collections to solve real-world problems.

Some examples included:

- Counting distinct users from a website access log using `Set`
- Calculating the total number of unique students enrolled in multiple courses
- Working with union, intersection and difference between sets
- Reading data from files and storing information in collections
- Consolidating election votes using `Map`
- Counting and grouping information through key-value structures

These exercises helped reinforce how collections can simplify data processing and eliminate duplicate information efficiently.
